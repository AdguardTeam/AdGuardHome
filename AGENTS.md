# AGENTS.md

## Changelog formatting (CHANGELOG.md)

- Add entries to the `## [Unreleased]` section between the "NOTE: Add new changes BELOW THIS COMMENT." and "NOTE: Add new changes ABOVE THIS COMMENT." markers.
- Within a `###` subsection, new entries go ABOVE older ones (newest first).
- Write each entry as a single-line bullet item matching the surrounding block's indentation — do not wrap entries onto continuation lines.
- Reference issues as `([#1234])` and add the link reference at the bottom of the block, keeping the list sorted and aligned with neighboring references.
- Do not reword or reorder existing entries.
